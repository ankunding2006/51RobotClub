# 数码管动态显示项目

欢迎使用该数码管动态显示项目。本项目基于8051单片机，通过超声波测距、数码管显示以及蜂鸣器报警实现距离测量与数据展示，并通过串口输出测量数据。

## 项目简介

- **项目名称**：数码管动态显示
- **平台**：8051单片机 (使用reg52系列)
- **主要功能**：
  - 采用超声波模块实时测量距离
  - 数码管动态显示距离数据（含小数点）
  - 距离过短时通过蜂鸣器报警
  - 串口输出距离数据，便于数据采集和调试

## 硬件连接

- **数码管显示模块**：连接到 P0 口
- **超声波模块**：
  - Trig（触发端）：连接到 P1.0
  - Echo（回波端）：连接到 P1.1
- **蜂鸣器**：连接到 P2.3

## 软件结构

- **主要文件**：
  - `smg_2.c`：主程序及所有功能实现代码，包含串口通信、超声波测距及数码管动态显示等功能
  - `README.md`：项目介绍及使用说明文件

- **功能模块**：
  - **超声波测距**：发送超声波脉冲，计算回波时间及距离，并做限幅处理
  - **数码管显示**：将计算后的距离数值转换为对应的段码，在四位数码管上依次显示
  - **蜂鸣器报警**：当距离低于设定阈值时，触发蜂鸣器报警提示
  - **串口通信**：初始化串口模块，格式化并发送距离数据用于调试或数据采集

## 使用方法

1. 请首先确认硬件连接正确无误，再将源码下载到您的8051单片机开发板上。
2. 修改工程编码为 UTF-8（若中文出现乱码）。
3. 编译并烧录程序，观察数码管显示、蜂鸣器报警及串口输出效果。
